# PoC 0 & PoC 1 — プロダクト仕様書 (Product Specification)

## 仮説 (Hypothesis)

「実用的なアプリを作ろう」と言われる**前に**、ソフトウェアのモジュール（ブロック）を並べ、つなぎ、外し、組み合わせて遊べるおもちゃがあれば、ユーザーの好奇心を刺激できるのではないか。本PoCはAIコード生成の賢さや商業的ポテンシャルではなく、**モジュールを組み合わせる体験（Composition Experience）そのものの面白さ**を検証する。

## 対象デモンストレーション（成人テスター向け・個人情報なし）

- ブラウザを起動すると、和モダン・からくり絵巻の世界観（黒漆と金箔のヘッダー、朱印、生成り和紙キャンバス、水引コード）で彩られたトイボックスとサンプルが表示される。
- **Message（文）**、**Character（からくり人形）**、**Timer（刻・砂時計）**、**Media Card（絵巻舞台）** の基本4種に加え、**Filter（言霊フィルター）**、**Counter（太鼓カウンター）** の計6種からブロックを選び、キャンバスに追加・ドラッグ移動し、型付きポートを確認できる。
- 出力ポート（Output）を互換性のある入力ポート（Input）へ水引で接続すると、決定論的に多段連鎖やアニメーション・吹き出し変化が起きる。
- **Message** ブロックの Send ボタンを押す -> 水引の上を金色の言霊玉が走り、接続された **Character** がジャンプし、受け取った言霊を頭上の吹き出しに表示する。さらに `landed` ポートから **Timer** の `start` ポートへ連鎖させることもできる。
- **Filter（言霊フィルター）** を間に挟むと、文を「🌸 雅（和歌調）」「⚔️ 武士（熱血）」「🎉 祭（関西ノリ）」に変換して次のブロックへ伝える。
- **Counter（太鼓カウンター）** を間に挟むと、指定回数（例：3回）叩かれたときのみ満願成就として `combo` 出力を発火する。
- **Timer** を開始する（手動または `start` 入力による連鎖、デモ用に1〜5秒） -> カウントダウン完了時に接続された **Media Card** のモック演舞状態が切り替わる（**実際の動画・音声ストリームは扱わない**）。
- 接続線を切る（Disconnect） -> 送信元の操作を行っても接続先は反応しなくなる。
- **Undo**（元に戻す） -> 切断された接続が戻り、イベント伝播が再開する。
- 不正な接続（出力→出力、未対応のイベント型 `notification`、自己ループ、閉路/サイクル）を試みると、わかりやすい警告メッセージが表示され、エッジは追加されない（グラフは変化しない）。
- **4種の絵巻プリセット（壱ノ巻〜肆ノ巻）**、**絵巻URL共有 (`#emaki=...`)**、および **🧪 からくり工房（JIDOKA認定カスタムブロック召喚）** により、発見・改造・共有のサイクルを1画面で完結できる。

## ブロック契約（Block contracts）

| ブロック (`BlockType`) | 出力ポート (Output ports) | 入力ポート (Input ports) | 実行時の動作 (Runtime action) |
|---|---|---|---|
| Message (`message`) | `sent`: `trigger` | なし | ユーザーが Send を押すとテキストペイロードと共に `trigger` を発火 |
| Character (`character`) | `landed`: `trigger`（着地連鎖用）<br>`jumped`: `notification`（予約・未対応型検証用） | `jump`: `trigger` | 短いジャンプアニメーションと受け取った言霊吹き出しを表示し、着地連鎖を発火 |
| Timer (`timer`) | `elapsed`: `trigger` | `start`: `trigger`（連鎖開始用） | 手動または `start` 入力でカウントダウンを開始し、終了時に `elapsed` を1回発火 |
| Media Card (`media-card`) | なし | `play`: `trigger` | 視覚的なモック再生状態（雅楽・花火演舞）をトグル |
| Filter (`filter` / 言霊フィルター) | `out`: `trigger` | `in`: `trigger` | 受け取った文を「雅（和歌調）」「武士（熱血）」「祭（関西ノリ）」に変換して次へ中継 |
| Counter (`counter` / 太鼓カウンター) | `combo`: `trigger` | `hit`: `trigger` | 指定回数（`targetCount`、デフォルト3回）に達したときのみ `combo` を発火 |

**ポート設計の原則：** 有効なイベント型は `'trigger'` に統一し、将来の拡張アイデアである `Character.jumped: notification` は予約済み（未対応イベント型 `UNSUPPORTED_PORT_TYPE` の検証用）として残すことで、PoC 0 の安全契約を100%維持したまま多段ピタゴラ連鎖を実現する。

## UX詳細 (UX details)

- デスクトップブラウザ優先（`1280x860` で全主要コントロールが見切れずに収まる設計）。狭い画面幅では1カラム等にフォールバックするレスポンシブ設計。
- 6種類のブロックは和の伝統色（藍・藤紫・琥珀・若竹・紅梅・朱赤）、家紋風アイコン、日本語タイトル、アクセシブルなラベルで識別可能にし、色だけに依存しないこと。
- 1〜2クリックで試せる発見しやすさ：初期ロード済みのサンプルに加え、4種の絵巻プリセットと「Empty（白紙）」ボタンを用意する。
- 仕組みが直感的にわかるよう、可視化されたイベントログ（からくり過去帳）と水引上の言霊玉アニメーションを表示する。
- 短いアニメーションには `prefers-reduced-motion`（視差・動きの軽減）への配慮を入れる。
- Undo は追加・削除・移動・接続・切断・プリセット切替を対象とし、以前の決定論的なグラフスナップショットを復元する。

## 受け入れシナリオ (Acceptance scenarios)

1. **初回起動 (Fresh launch)**：`Message → Character` と `Timer → Media` のペアを含む初期絵巻が読み込まれる。
2. **接続中の送信 (Send while connected)**：Send を押すと Character が1回ジャンプし、イベントログに1件のディスパッチが記録される。
3. **接続の削除 (Remove edge)**：接続を外して Send を押しても Character は変化しない。
4. **切断のUndo (Undo disconnection)**：Undo 後に再度 Send を押すと、再び Character がジャンプする。
5. **不正接続の試行 (Attempt illegal self-edge / incompatible port)**：グラフ構造は一切変化せず、警告が表示される。
6. **タイマー開始 (Start Timer)**：カウントダウン後に `elapsed` イベントが1回だけ発火し、再レンダーで重複発火しない。タイマーブロック削除時にはタイマーがキャンセルされる。
7. **多段からくり連鎖と太鼓コンボ (PoC 1 Multi-stage & Combo)**：弐ノ巻で5段連鎖が完走し、参ノ巻で3回送信時にのみコンボが発火する。
8. **アクセシビリティとレイアウト (Accessibility & Layout)**：基本ボタンにキーボードフォーカスが当たり、一般的なノートPC画面幅（`1280x860`）で主要な操作コントロールが見切れない。

## スコープ外 (Out of scope)

実行時のAI生成、永続アカウント、クラウド保存、公開・パブリッシュ、共同編集、実際のメッセージ送受信や動画配信、外部サービス連携、課金、カスタムスクリプト、モデレーション、モバイルネイティブアプリ。

## 人間による観察・検証項目 (Human research questions)

- 最初の自発的な操作までに何秒かかったか？
- 説明なしでキャラクターを反応させることができたか？
- 接続を切ったあと、再接続したか、それとも別の組み合わせやプリセットを試したか？
- 他の人に見せたくなるくらい面白いと感じたか？
- 設計者が意図していなかったどんな驚きや発見が起きたか？

見た目の美しさやAIコーディングの凄さと、「モジュールを組み合わせること自体の本質的な楽しさ」を混同しないこと。
