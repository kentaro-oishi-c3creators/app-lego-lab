# App LEGO PoC 1 — 全部入りパック × 和モダン「からくり絵巻」実装計画

## 1. コンセプト：「和モダン・からくり絵巻 (Wa-Modern Karakuri & Washi Studio)」

PoC 0 の全22テストおよび JIDOKA ゲート（G01〜G07）との完全互換性を維持したまま、ユーザー承認のもとスコープを拡張し、**4大アイデアのすべて**と**見た人が感動する「和」の伝統美デザイン**を融合させます。

### デザインシステム（日本の伝統色 × 工芸モチーフ）
- **背景・キャンバス（生成り和紙 × 麻の葉・青海波透かし文様）**：温かみのある和紙色（`#fbf7ee`）に繊細な和柄ドットグリッドを配し、目に優しく品格のある作業空間を実現。
- **ヘッダー・動作記録（黒漆・墨色 × 金箔・朱印）**：深みのある黒漆色（`#1a1615`）に金箔色（`#d4af37`）の飾り罫と、朱色の**落款印（ハンコ「巧」バッジ）**を配置。
- **水引（みずひき）風の結線と「光る言霊玉」の伝播演出**：
  - ブロック間をつなぐベジェ曲線を金・朱・藍の**水引コード**として表現。
  - イベント発火時には、結線の上を**金色の光る言霊玉（SVG アニメーション）**が滑らかに走る視覚演出を追加。
- **6種の「からくりブロック」意匠（色・紋章・枠線種別で識別）**：
  1. **💬 文（Message）**：藍色（Ai-iro）× 実線枠 — 言霊（メッセージ）を送り出す
  2. **⛩️ 言霊フィルター（Filter）**：紅梅色（Kobai）× 点鎖枠 — 言葉を「🔥熱血武士」「🌸雅（みやび）和歌」「🎉関西ノリ」へ変換
  3. **🥁 太鼓カウンター（Counter）**：茜・朱色（Shu-iro）× 太破線枠 — 3回叩くと大技トリガーを発動
  4. **🎎 からくり人形（Character）**：江戸紫（Edo-Murasaki）× 二重枠 — セリフ吹き出しと桜吹雪・金扇を舞わせてジャンプ（さらに `landed` 出力ポートで次のブロックへ連鎖！）
  5. **⏳ 刻・砂時計（Timer）**：琥珀・山吹色（Kohaku）× 破線枠 — `start` 入力ポート解禁により連鎖起動可能、完了時に `elapsed` を発火
  6. **🏮 絵巻・舞台（Media Card）**：常盤・抹茶緑（Tokiwa）× 飾り枠 — 雅楽・祭囃子風の視覚モック舞台と桜吹雪エフェクト

## 2. 全部入り4大機能のアーキテクチャ設計

### ① ピタゴラスイッチ多段連鎖（Rube Goldberg Chain）
- **既存テスト互換の維持**：PoC 0 の `Character.jumped (notification, 予約)` はそのまま残し（G02 の未対応ポート拒否テストを100%維持）、新たに **`Character.landed (着地連鎖: trigger)`** 出力ポートと **`Timer.start (計測開始: trigger)`** 入力ポートを追加。
- **`RuntimeDriver` の連鎖実行**：`Character` がジャンプ着地した際や `Counter` が規定回数に達した際、`Filter` を通過した際に次のイベントが連鎖発火し、`Message → Filter → Character → Timer → Media Card` の**全自動ピタゴラ連鎖**が成立。
- **太鼓カウンター (`counter`)**：`hit (trigger)` 入力を受け取り、カウント（例：3回）に達した瞬間に `combo (trigger)` 出力を発火してリセット。

### ② 言霊・気分データの伝播（Typed Payload & Speech Bubble）
- `Message` の送信テキストが `Filter` を通ると、選択中のモード（`bushido`: 武士語録 / `miyabi`: 雅な和歌調 / `kansai`: 関西ノリ）に変換され、`Character` の頭上に**和風吹き出し**として表示されながらジャンプ。

### ③ からくり絵巻プリセット集 ＆ 🔗 ワンクリックURL共有
- 画面上部でワンクリック切り替えできる4種のプリセット：
  1. **📜 壱ノ巻：基本の二対（PoC 0 標準）**
  2. **🎎 弐ノ巻：からくり五段ピタゴラ連鎖**（`Message → Filter → Character → Timer → Media Card`）
  3. **🥁 参ノ巻：三連太鼓の必殺奥義**（`Message → Counter(3回) → Character + Media Card`）
  4. **🌸 肆ノ巻：千本桜・一斉演舞**（1つの `Message` から複数ブロックが一斉に舞う）
- **🔗 絵巻URL共有**：現在のグラフを Base64URL エンコードして URL ハッシュ（`#emaki=...`）に保存＆クリップボードコピー。URLを開くだけで `sanitizeGraph` を通して安全に復元。

### ④ 🧪 からくり工房（JIDOKA 安全検査付きカスタムブロック召喚）
- 実行時外部APIゼロで動作する「🧪 からくり工房」パネル。
- ブロック種別・銘（ラベル）・言霊スタイルや回数を選び **「いざ召喚（JIDOKA検査）」** を押すと、画面上でリアルタイムに `G02/G06 安全性検査（型整合性・eval禁止・文字数制限） → STATUS: PASS` の朱印が押され、キャンバスにオリジナルブロックが追加される。
