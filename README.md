## 1文で表す実験内容 (One-sentence experiment)

初めてのユーザーが説明なしでトイブロック（文・言霊フィルター・太鼓カウンター・からくり人形・砂時計・絵巻舞台）を配置・水引で結線し、表舞台のアニメーションと和楽器サウンドで多段ピタゴラ連鎖の驚きを観察し、線を切って反応が止まることを確かめ、Undo（元に戻す）やURLハッシュで自在に復元・共有できるか？

**PoC 0 / PoC 1** は実行時に完全オフライン・決定論的に動作します。実行時の LLM/AI API 呼び出し、アカウント認証、クラウド保存、外部通信、課金、実データの取り込み、任意コード実行（`eval` 等）は一切行いません。

## デモ操作手順 (Demo Steps)

1. **起動と初期サンプル確認**：[公開デモサイト (GitHub Pages)](https://kentaro-oishi-c3creators.github.io/app-lego-lab/) または `npm run dev` でブラウザを開くと、初回は「秘伝指南書 & 紹介スライド」が表示されます。閉じると、上段に **「🎭 表舞台：からくり実演シアター」**、下段に **「⚙️ 裏の仕掛け：からくり配線キャンバス」** が表示されます。
2. **舞台実演（Message → Character）**：シアター右上の **「🎬 舞台で実演スタート！(送信)」** または `Message (msg-1)` の **「📨 Send (送信)」** ボタンを押すと、琴の音（ポロロン♪）とともに水引を金色の言霊玉が走り、小鼓の音（ポンッ！）で檜舞台のからくり人形が大ジャンプして吹き出しが表示されます。
3. **切断 (Disconnect)**：水引にある **「✂️ 切断」** ボタンを押してから送信すると、三味線のズレ音とともにシアター上に **「✂️ 水引が切れているため、人形に言霊が届きません！」** と表示され、なぜ動かないかが直感的にわかります。
4. **元に戻す (Undo)**：上部ツールバーの **「↩️ Undo (戻す)」** を押すと水引が復元され、再び人形が踊り出します。
5. **Timer → Media Card の動作確認**：`Timer (timer-1)` の **「▶️ Start Timer (3s)」** を押すと、拍子木の音で砂時計がカウントダウンし、3秒後に半鐘の音と打ち上げ花火（ヒュー…ドォーン！）で `Media Card (media-1)` の大舞台が開演します。
6. **PoC 1 新機能（全部入り・からくり実演シアター＆和楽器サウンド）**：
   - **📜 4種の絵巻プリセット**：「📜 壱ノ巻：基本の二対」「🎎 弐ノ巻：からくり五段連鎖」「🥁 参ノ巻：三連太鼓の奥義」「🌸 肆ノ巻：千本桜・一斉演舞」をワンクリックで切り替えられます。
   - **🔊 Web Audio API 和楽器シンセサイザー**：琴・風鈴・神楽鈴・小鼓・和太鼓・拍子木・半鐘・打ち上げ花火をブラウザ内でリアルタイム合成（試聴ボタン＆ミュート切替付き）。
   - **⚡ ステップバイステップ連鎖リレー実況**：`STEP 1 ➔ STEP 2 ➔ STEP 3 ➔ STEP 4` の進行カードとキャンバス上のスポットライトが順番に点灯し、連鎖の流れを目で追えます。
   - **🧪 からくり工房（JIDOKA 認定カスタムブロック召喚）** ＆ **🔗 絵巻URL共有 (`#emaki=...`)**。
