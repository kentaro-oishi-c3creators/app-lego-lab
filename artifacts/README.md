# Generated outputs

Put public-safe, reproducible run artifacts here: screenshots, test reports, demo recordings, package builds if needed. Prefer links from `experiments/<run>/README.md`. Generated build output (`dist/`, `node_modules/`) is Git-ignored by default; upload large binary files to a release or Drive and link back, do not commit sensitive or bulky media. Never commit token files, private screenshots, self-analysis or client data.
